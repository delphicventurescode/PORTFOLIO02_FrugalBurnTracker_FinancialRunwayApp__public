# PORTFOLIO02 — Frugal Burn Tracker: Financial Runway App

**A Flask + SQLite web application for analyzing financial runway, burn rate, expenditure, and cash sustainability.**

The **Frugal Burn Tracker — Financial Runway App** is Portfolio Project #02, building on the Frugal Burn Tracker developed as Portfolio Project #01.

The application is designed around a simple financial question:

> **How long can the available cash sustain the current level of spending?**

It provides a lightweight interface for analyzing burn rate and financial runway while distinguishing between different types of expenditure.

## Financial Runway

The central concept of this application is **financial runway**.

Financial runway provides a way of thinking about available cash in relation to the rate at which that cash is being consumed.

The application brings together:

* Available cash
* Income
* Expenses
* Burn rate
* Essential expenditure
* Discretionary expenditure
* Projected runway

This makes it possible to explore the relationship between spending decisions and the amount of time available before available funds are exhausted.

## Development Approach

This application was developed using **Google Antigravity**, an AI-powered coding agent.

The development process demonstrates a human-directed, AI-assisted software development workflow:

1. Define the desired application and requirements.
2. Direct the AI coding agent to implement the requirements.
3. Review the generated application.
4. Run and test the application.
5. Direct targeted modifications where required.
6. Verify that the resulting application continues to function correctly.

For this version, the visual presentation was specifically directed toward a **professional blue-and-white color palette**, while preserving the application's existing functionality, calculations, database schema, routes, and page structure.
