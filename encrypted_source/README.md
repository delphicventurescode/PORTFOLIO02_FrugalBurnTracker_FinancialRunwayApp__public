# Encrypted Source

This directory contains the source files for **PORTFOLIO02 — Frugal Burn Tracker: Financial Runway App** in an encrypted, password-protected archive.

The archive contains the project files for the Flask/SQLite web application, including the application source code, templates, static assets, database schema, tests, and related project documentation.

## Contents

The project has been packaged as a **ZIP archive and encrypted/password-protected** before being uploaded to this repository.

### Project

**PORTFOLIO02 — Frugal Burn Tracker: Financial Runway App**

* **Framework:** Flask
* **Database:** SQLite
* **Language:** Python
* **Development tool:** Google Antigravity

## Access

The archive is intentionally password-protected.

**The password is not stored in this repository.**

If you have been provided with the password, use it to extract the archive locally.

For information about the project itself, please see the main repository README.

## Relationship to PORTFOLIO01

PORTFOLIO02 is a subsequent portfolio version of the **Frugal Burn Tracker** developed as PORTFOLIO01.

The application focuses on financial runway and burn-rate analysis, while this version also reflects a subsequent visual refinement of the application.

The encrypted archive represents the project files as packaged for this portfolio repository.
